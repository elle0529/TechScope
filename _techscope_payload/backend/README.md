# TechScope FastAPI Classic RAG

Source responsibility:

1. Azure AI Search performs classic hybrid retrieval.
2. Query embeddings are generated by the configured Azure OpenAI embedding deployment.
3. Retrieved chunks are passed to Azure OpenAI Responses API.
4. The model is instructed to answer only from retrieval context.
5. API response returns grounded metadata: chunk/source/technology/category/architecture/evidence/company.
6. `grounded_technology_ids` is the backend-side input for the authoritative
   `BridgeAIRequestTechnology` relation once Cosmos/SQL operation persistence is wired.

No cloud execution is claimed by P2A.
